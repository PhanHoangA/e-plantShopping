# Paradise Nursery Shopping Application

## Project Overview
Paradise Nursery is a dynamic online plant shopping cart application built with React and Redux Toolkit. Users can browse a wide variety of houseplants grouped by categories, view plant details (thumbnail, name, description, and price), add items to their shopping cart, dynamically adjust item quantities, and view real-time total cost calculations.

## Key Features
- **Landing Page**: Welcomes users to Paradise Nursery with company background information and a "Get Started" navigation button.
- **Product Listing**: Displays at least six unique houseplants across three distinct categories with real-time "Add to Cart" state management.
- **Shopping Cart**: Dynamically calculates subtotal per item and total cart amount, supports incrementing/decrementing quantities, deleting items, and continuing shopping.
